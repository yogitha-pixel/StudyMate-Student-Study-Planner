# 📚 StudyMate - Student Study Planner

A simple and effective web-based study planner designed for students to organize, track, and manage their study tasks efficiently.

## ✨ Features

- **📋 Task Management**: Add, view, and manage study tasks
- **📊 Dashboard**: Real-time statistics showing total, completed, and pending tasks
- **🎯 Priority Levels**: Organize tasks by High, Medium, and Low priority
- **✅ Task Completion**: Mark tasks as completed or revert them
- **🗑️ Delete Tasks**: Remove tasks you no longer need
- **💾 Local Storage**: All tasks are saved in browser's local storage
- **📱 Responsive Design**: Works seamlessly on desktop and mobile devices

## 🚀 Quick Start

1. **Open the Application**
   - Simply open `index.html` in any modern web browser

2. **Add a Study Task**
   - Fill in the form with:
     - Subject name (e.g., Java, Mathematics)
     - Topic (e.g., Inheritance, Calculus)
     - Date and time of study
     - Priority level
   - Click "Add Study Task"

3. **Manage Your Tasks**
   - View all your tasks in the task list
   - Mark tasks as completed with the green button
   - Delete tasks with the red button

## 💡 How It Works

1. Tasks are stored in the browser's `localStorage`
2. When you add a task, it's immediately saved
3. When you complete or delete a task, the changes are persisted
4. The dashboard updates in real-time to show task statistics
